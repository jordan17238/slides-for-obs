This installs Slides for OBS, which displays LibreOffice Impress (.odp) and PowerPoint (.pptx) presentations directly inside OBS Studio as a native source.

The plugin will be installed to:
/Library/Application Support/obs-studio/plugins/

Please quit OBS Studio before continuing. If OBS is running, it will keep using the old version until you restart it.

You also need these installed:

  • OBS Studio 30 or newer
  • LibreOffice — used to convert your presentations. Free from libreoffice.org. The plugin cannot render slides without it.
  • Poppler — provides pdftoppm, used to turn pages into images. Install with Homebrew:
    brew install poppler

You can install these afterwards if you don't have them yet — the plugin will simply report them as missing in the OBS log until they are present.
