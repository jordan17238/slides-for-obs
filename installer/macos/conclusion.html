Slides for OBS is installed.

Next: start (or restart) OBS Studio, then add a source:
+ → ODP Presentation, and choose your .odp or .pptx file.

If slides don't appear, check the OBS log (Help → Log Files → View Current Log) for lines starting with [odp-presenter]. Near the top it reports which tools it found:

  • LibreOffice: NOT FOUND — install LibreOffice from libreoffice.org.
  • pdftoppm: not found — install poppler: brew install poppler

Both are separate free downloads and are not bundled with this plugin.

The first time you add a deck it converts the whole presentation, which can take from a few seconds to a couple of minutes depending on its size. After that it is cached and loads instantly until you edit the file.
